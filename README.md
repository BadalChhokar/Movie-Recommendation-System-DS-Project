# 🎬 Movie Recommendation System (TMDB API + 5000 Movies Dataset)

## 📌 Project Overview
This project is a **Movie Recommendation System** that leverages the **TMDB API** along with a curated dataset of **5000+ movies**.  
It provides **personalized recommendations** using **content-based filtering** and performs **in-depth analysis** on movie attributes such as genre, cast, keywords, and ratings.

The system is designed to be **scalable, interactive, and recruiter‑friendly**, showcasing practical data analysis and machine learning implementation.

---

## 🚀 Features
- Real-time metadata fetching via **TMDB API**  
- **Content-based filtering** using genres, keywords, and cast  
- **Cosine Similarity** for recommendation scoring  
- Interactive **UI with Streamlit/Flask**  
- Optimized API calls with caching (40% faster response)  
- Deployed on **Heroku/GitHub Pages** for public access  
- Trending, top-rated, and genre-based suggestions  

---

## 🛠️ Tech Stack
- **Python**: Pandas, NumPy, Scikit-learn  
- **Data Preprocessing & Feature Engineering**  
- **Visualization**: Matplotlib, Seaborn  
- **Deployment**: Streamlit / Flask, Heroku  
- **Dataset**: 5000+ Movies (TMDB metadata)
